# Legacy ArcGIS References

These files preserve reviewed ArcGIS application definitions used to reconstruct behavior in Hub 3.0. They are reference material only and are not runtime data sources.

- `arcgis-dashboard-survey-release-lists.json`: former ArcGIS Dashboards definition for the separate **Next releases** and **Recent releases** monitoring lists. Its filters, ordering, expected-publication calculation, exclusions, and link patterns informed the unified live survey pipeline on `/monitoring`.
