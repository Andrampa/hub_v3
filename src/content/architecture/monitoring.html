DIEM household monitoring system · V3

How a household survey becomes a public dashboard

One questionnaire defines the structure. Each survey passes through review gates into a permanent archive, is summarised in the database, and is published to ArcGIS Online, where the monitoring app and the Hub read it.

Target architecture after the real-data rebuild · As of 13 October 2026.

How to read this diagram
  1. Start with the questionnaire metadata: it defines the structure used throughout the pipeline.
  2. Follow the provider export through privacy clearance, standardisation, cleaning and human review.
  3. Read Step 3 from the permanent archive through the country working table and summary views.
  4. Finish at ArcGIS Online: private sources feed filtered public views and restricted microdata grants.

Metadata first

No stage hardcodes the survey structure. The SMAR questionnaire is parsed once into registries of fields, coded domains and derived fields. Those registries drive Step 1 renaming, the table definitions, the summary-view SQL, the AGOL service layout and the app's labels. A new questionnaire version means regenerating this band, not editing the stages below it.

Two household tables

The global table is the permanent archive and only ever grows by reviewed appends. The working table holds one country and at most six rounds, so view refreshes stay fast as history accumulates. Step 3 rebuilds it from the global table for each survey, refreshes the views, then publishes a single country-round slice by delete-then-append.

Private by default

Every AGOL table is a private source service with a hosted view filtered to opendata = 1. Every survey is loaded with opendata = 0 until the data manager approves production. Restricted microdata leaves only through time-limited grants to one named recipient.

Audit without data

A private Git repository records who owns each survey, the hash of the cleared file, decisions and operation receipts. Survey files travel through SharePoint and never through Git. Agents run only allowlisted database operations and never see credentials.

What changes with the rebuild

The flow above is the same today. The differences are in the database layer and in how services are shared.
