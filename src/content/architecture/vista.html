DIEM flood services · VISTA, VIIRS Surface Water Temporal Atlas

How NOAA flood composites become a global flood reference

An operator builds dekadal rasters on a workstation and uploads them to Google Cloud. Earth Engine computes the multi-year statistics. The public reads one bucket and one Earth Engine project, and EVE uses the monthly flood frequency to tell seasonal from exceptional flooding.

Current implementation; planned components labelled separately · As of 21 October 2026.

How to read this diagram
  1. Start with the operator configuration and NOAA five-day flood composites. Phase 1 builds dekadal rasters; Pipeline B recovers logged gaps.
  2. Follow Phase 2 through Cloud Storage into the Earth Engine dekadal archive.
  3. Read the statistics in dependency order: dekadal counts and frequency, the rolling monthly archive, then monthly statistics. Phase 3B mosaics dekadal exports.
  4. Finish at the public delivery paths and EVE’s monthly flood-frequency input. Dotted boxes are planned; dashed boxes are implemented conditional steps. Every phase is started by an operator.

Gaps stay visible

A dekad is built only when every scheduled 5-day composite exists. A missing composite stops that dekad and is appended to availability_issues_log.csv, which also records missing tiles and unequal coverage. Pipeline B reads that log and rebuilds only the logged dekads from the GMU archive, with a _pipeB suffix. Rejected dekads in quality_control.yaml are kept out of Phases 2 to 5.

Earth Engine does the statistics

Phase 3 stacks every year of the dekadal archive by recurring dekad and counts each class. Frequency and dominant class are derived from those counts, so count must finish first. Phase 4 builds a centred three-dekad monthly archive, and Phase 5 repeats the statistics on it. Existing assets are always skipped; regenerating one means deleting it by hand first.

One bucket, several doors

The same objects reach users four ways: the website's bucket browser, Earth Engine apps and scripts, ArcGIS Online layers, and later a FAO STAC collection. The website is static and has no sign-in. It asks for a credit acknowledgement before each download. ArcGIS Online items are created private and shared by hand.

Run by hand, in order

No phase runs on a schedule. The operator edits config.yaml, runs a dry run, then executes, and waits for Earth Engine export tasks before the next phase or the Phase 3B mosaic. Several operators can work at once only on non-overlapping dekads, because every output name is deterministic.
